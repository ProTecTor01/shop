# Shop

Shop — небольшой магазин объявлений на Ruby on Rails. Пользователь регистрируется, публикует товар, меняет и удаляет свои объявления. Товары можно складывать в корзину до и после входа в аккаунт. Оплаты в приложении нет: корзина показывает состав и итоговую стоимость.

## Что умеет приложение

- Продавец выбирает категорию при создании или изменении объявления. На главной странице покупатель может отфильтровать товары по категории.
- На главной странице видны товары, цены, состояния и имена продавцов.
- Кнопка **Sell** позволяет авторизованному пользователю создать объявление с названием, ценой, моделью, описанием, брендом, цветом (поле `Finish`), состоянием и изображением с компьютера.
- Редактировать и удалять объявление может только его автор. Это проверяется и в интерфейсе, и в контроллере.
- Корзина доступна без входа. Повторное добавление товара увеличивает количество. Иконка в меню показывает число единиц товаров. На странице корзины есть сумма, удаление одной единицы и очистка всей корзины с подтверждением.
- После входа гостевая корзина объединяется с корзиной пользователя. Корзины разных пользователей не смешиваются.
- Сообщения о добавлении и удалении товара исчезают через 4 секунды.

## Быстрый запуск

Нужны **Ruby 3.2.6**, Bundler и SQLite3. Приложение использует Rails 6.1.7.10. Node.js и Yarn для запуска не нужны.

```bash
bundle install
bin/rails db:prepare
bin/rails db:seed
bin/rails server
```

Откройте `http://localhost:3000`. Команда `db:seed` добавляет десять демо-объявлений от двух продавцов (`user@example.com` и `seller2@example.com`, пароль у обоих — `password`). Запускать её повторно безопасно: объявления не дублируются. Для проверки регистрации создайте нового пользователя через **Sign up**.

Если запускаете проект на Windows, используйте установленный Ruby или WSL. Убедитесь, что команды `ruby --version` и `bundle --version` доступны в выбранном терминале. SQLite база появится локально в `db/development.sqlite3`; загруженные изображения сохраняются в `public/uploads`. Эти файлы не попадают в Git.

## Как пользоваться

1. Откройте главную страницу и нажмите **Sign up**. После регистрации можно нажать **Sell**, заполнить форму объявления и выбрать категорию.
2. На главной странице выберите категорию и нажмите **Filter**, чтобы увидеть только нужные товары. Добавьте товар в корзину с карточки или со страницы товара. Кнопка **Cart** в меню откроет товары и итог.
3. Нажмите **Remove one**, чтобы уменьшить количество конкретного товара на единицу. **Empty Cart** очищает корзину после подтверждения и возвращает на главную.
4. Для проверки гостевой корзины выйдите из аккаунта, добавьте товар и снова войдите. Товар сохранится в корзине этого аккаунта.

## Устройство проекта

| Часть | Назначение |
| --- | --- |
| `app/models/user.rb`, `product.rb` | Продавцы и объявления. |
| `app/models/cart.rb`, `line_item.rb` | Корзина, количество товаров и итоговая сумма. |
| `app/models/concerns/current_cart.rb` | Выбор корзины гостя или пользователя и перенос товаров при входе. |
| `app/controllers/registrations_controller.rb` | Разрешённые поля регистрации и изменения профиля Devise. |
| `app/controllers/products_controller.rb` | Объявления и проверка автора при изменении и удалении. |
| `app/controllers/carts_controller.rb`, `line_items_controller.rb` | Просмотр, добавление и удаление товаров из корзины. |
| `app/views/` | Страницы и формы. |
| `db/migrate/` | Структура базы данных. |

## Проверка

```bash
bin/rails test
```

Интеграционные тесты в `test/integration/shop_flow_test.rb` проверяют регистрацию и вход, изменение профиля, права двух пользователей на объявления, выбор и фильтрацию категорий, отображение продавца, создание и удаление объявлений, счётчик и сумму корзины, удаление одной единицы, раздельные корзины и перенос гостевой корзины после входа. Исходный список требований находится в `shop__ts.md`. Пункты в разделе **Bonus** необязательны; категории, добавление с главной и удаление одной единицы реализованы, платёжный сервис не подключён.
